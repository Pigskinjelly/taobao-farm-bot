# taobao-farm-bot · 芭芭农场浏览任务自动化

一个**可观测、可中断、可留证**的 Android UI 自动化项目：在本人设备、本人账号上，
把「淘宝 → 芭芭农场 → 集肥料 → 做任务赚肥料 → 逐条浏览」这条重复路径自动化。

> 只做页面**明确提供**的浏览任务。不处理验证码、不伪造浏览、不改系统时间、
> 不绕过任何风控；命中验证/风险提示立即停机并请求人工。

## 为什么这个项目值得看

淘宝农场是 Themis/H5 容器，**关键控件不暴露给无障碍服务**。本项目把这条坑走完了，
留下三种感知通道的实现与取舍数据：

| 通道 | 农场底栏「集肥料」 | 任务面板「去完成」 | 说明 |
|---|---|---|---|
| `adb shell uiautomator dump` | ❌ 崩溃（`dumpNodeRec` NPE） | ❌ 崩溃 | Android 8.x 在动画页面必现，进程被 SIGKILL |
| uiautomator2（ATX server） | ❌ 不暴露 | ❌ 不暴露 | 不崩、0.4s，但 H5 节点只给一部分 |
| **截图 + OCR（本项目主力）** | ✅ 精确命中 | ✅ 每行可读 | RapidOCR 离线识别，2.6s/帧 |

结论：**H5 页面靠无障碍读不全时，OCR 才是稳定解**。细节见 [DESIGN.md](DESIGN.md) 第 13、14 章。

## 功能

- 自动进入农场、点开「做任务赚肥料」面板
- 识别并执行**浏览类**任务，自动跳过安装/下单/答题/支付/支付宝跳转等高风险项
- 三种浏览页形态都支持：
  - 普通「浏览 15 秒」→ 读倒计时，归零返回
  - 「滑动浏览得肥料」浮标 → **持续滑动**把时长读完
  - 「搜一搜」需要输入 → **点一个历史搜索词**代替输入
- 可重复任务（如 `0/26`）按配额做满
- 被平台限流（「开小差了／人数较多」）→ 回淘宝首页冷却 5 分钟 → 重进农场 → 继续
- 全程日志 + 关键截图；支持 `--dry-run` 演练、`--probe` 只识别不点击

## 快速开始

```bash
git clone <this-repo> && cd taobao-farm-bot

# 1. 依赖
pip install -r requirements.txt

# 2. adb（因体积原因未入库，自行下载后放到 tools/platform-tools/）
#    https://developer.android.com/tools/releases/platform-tools
tools/platform-tools/adb.exe devices      # 必须显示 device

# 3. 离线自检（不需要手机）
python selftest.py                        # 期望：通过 63 项

# 4. 看一眼当前页面能不能读
python run.py --probe

# 5. 演练 → 真跑
python run.py --visual --dry-run --max-ads 2
python run.py --visual --max-ads 60 --cooldown 300
```

手机侧要求：解锁、淘宝已登录、USB 调试已授权、屏幕常亮
（`adb shell svc power stayon true`）。

## 安全边界（硬编码，不提供开关）

- 所有点击都基于**当前屏幕可见的文本/控件**，禁止硬编码坐标盲点；
- 按钮必须命中白名单（去完成/去观看/去浏览/立即领取），且所在行必须出现「浏览」；
- 行内出现 `安装 / 下载 / 开启 / 下单 / 购买 / 支付 / 付款 / 结算 / 充值 / 支付宝 /
  答题 / 前往 / 邀请` 一律跳过；
- 出现 `验证码 / 滑块 / 安全验证 / 账号异常 / 环境异常` → 立即停机并截图；
- 不自动输入密码、不自动处理验证码、不切换账号（默认关闭）、不修改系统设置。

真机面板里奖励最高的两项恰好都是高危的——「安装桌面访问小组件 +30000」和
「百亿补贴双11大额肥料（页面下单赚5万+肥料）+57000」，按钮同样是「去完成」。
所以黑名单是硬约束，并由 `selftest.py` 的断言守住。

## 已知限制

- 只在 **荣耀 8X / Android 8.1 / 淘宝 10.68.10 / 720×1520** 上做过完整实测；
  其他分辨率与版本需重新跑 `--probe` 校准；
- OCR 每帧约 2.6~3.5 秒，单条任务 40~140 秒，跑满 26 次需要较长时间；
- 平台会限流：高频约 20 分钟后出现「开小差了」，脚本会冷却 5 分钟后重试，
  连续冷却 4 次仍失败则停机；
- 中文输入未实现（`adb shell input text` 不支持中文），「搜一搜」改为点历史搜索词。
